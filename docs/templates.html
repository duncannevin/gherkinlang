Project Templates

GherkinLang provides templates to quickly bootstrap new projects.

gherkin init my-project --template <template-name>

Basic Template

Minimal setup with one example feature file.

gherkin init my-project --template basic

Files Created

  • .gherkinrc.json - Configuration file
  • features/example.feature - Simple example

Example Feature

Feature: Example
  A simple example to get started with GherkinLang.

Scenario: Add two numbers
  Given the first number is 5
  And the second number is 3
  When I add them together
  Then the result should be 8

Best for: Learning GherkinLang, quick prototypes

Library Template

Utility functions for math and string operations.

gherkin init my-lib --template library

Files Created

  • .gherkinrc.json - Configuration file
  • features/math.feature - Mathematical utilities
  • features/strings.feature - String manipulation

Math Feature

Feature: Math
  Mathematical utility functions.

Scenario: Calculate factorial
  Given a number n
  When I calculate factorial of n
  Then the result is n! (n factorial)

Scenario: Check if prime
  Given a number n
  When I check if n is prime
  Then the result is true if n has exactly 2 divisors

Strings Feature

Feature: Strings
  String manipulation utilities.

Scenario: Capitalize a string
  Given a string text
  When I capitalize the string
  Then the first character is uppercase and the rest lowercase

Scenario: Reverse a string
  Given a string text
  When I reverse the string
  Then the characters are in opposite order

Best for: Utility libraries, npm packages

API Template

Full-featured Express.js CRUD API with authentication.

gherkin init my-api --template api

Files Created

  • .gherkinrc.json - Configuration (ESM format)
  • features/database.feature - In-memory database service
  • features/validation.feature - Input validation utilities
  • features/users.feature - User CRUD operations
  • features/products.feature - Product CRUD operations
  • features/auth.feature - Authentication service
  • features/responses.feature - HTTP response formatting
  • features/health.feature - Health check endpoint
  • features/app.feature - Express.js application

Database Service (State Management)

Feature: DatabaseService
  In-memory database service for storing application data.

Background:
  Given import date-fns as dateFns
  And initial state is { collections: {}, nextId: 1 }
  And state accepts messages:
    | insert    | add record to collection with auto id |
    | findById  | return record by id from collection   |
    | findAll   | return all records from collection    |
    | findWhere | return records matching filter        |
    | update    | update record by id in collection     |
    | delete    | remove record by id from collection   |
    | clear     | remove all records from collection    |

API Endpoints

Method Path Description
GET /health Health check
POST /auth/register User registration
POST /auth/login User login
GET /users List all users
GET /users/:id Get user by ID
POST /users Create user
PUT /users/:id Update user
DELETE /users/:id Delete user
GET /products List all products
GET /products/:id Get product by ID
POST /products Create product
PUT /products/:id Update product
DELETE /products/:id Delete product

Best for: REST APIs, web services, backend applications

Using Templates

# Interactive template selection
gherkin init my-project

# Non-interactive with specific template
gherkin init my-project --template api --yes

# Initialize in current directory
gherkin init . --template library
Tip: After initialization, run gherkin start to compile all features and start watching for changes.
