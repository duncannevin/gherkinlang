Quick Example

Write a feature specification:

Feature: Calculator
  A simple calculator for basic math operations.

Scenario: Add two numbers
  Given two numbers a and b
  When I add them together
  Then the result is a + b

Scenario: Calculate factorial
  Given a positive integer n
  When I calculate the factorial
  Then the result is n! (n factorial)

Run the compiler:

$ gherkin compile features/calculator.feature

Get production-ready JavaScript:

/**
 * Add two numbers
 * @param {number} a - First number
 * @param {number} b - Second number
 * @returns {number} The sum
 */
export const add = (a, b) => a + b;

/**
 * Calculate factorial
 * @param {number} n - Positive integer
 * @returns {number} n factorial
 */
export const factorial = (n) =>
  n <= 1 ? 1 : n * factorial(n - 1);
