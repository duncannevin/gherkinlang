Getting Started

Get up and running with GherkinLang in just a few minutes.

Installation

Install GherkinLang globally using npm:

npm install -g gherkinlang-js

Or add it as a project dependency:

npm install --save-dev gherkinlang-js

Requirements

  • Node.js 18 or higher
  • Anthropic API key (for AI transformation)

API Key Setup

Set your Anthropic API key as an environment variable:

export ANTHROPIC_API_KEY="your-api-key-here"

Quick Start

The fastest way to get started is with the start command:

# Create a new project
gherkin init my-project --template basic

# Enter the directory
cd my-project

# Compile and watch
gherkin start

Project Initialization

Create a new GherkinLang project with the init command:

gherkin init [directory] [options]

Available Templates

Template Description
basic Minimal setup with one example feature
library Utility functions with math and string examples
api Full Express.js CRUD API with users, products, auth

Use the --template option to select a template:

gherkin init my-api --template api

Your First Feature

Create a new feature file in features/:

# features/greeting.feature

Feature: Greeting
  Generate personalized greeting messages.

Scenario: Say hello
  Given a person's name
  When I create a greeting
  Then the result is "Hello, {name}!"

Scenario: Say goodbye
  Given a person's name
  When I create a farewell
  Then the result is "Goodbye, {name}!"

Compiling

Compile your feature files to JavaScript:

# Compile a single file
gherkin compile features/greeting.feature

# Compile all features in a directory
gherkin compile features/

# Specify output directory
gherkin compile features/ --output dist/

The compiler will generate:

  • dist/greeting.js - The compiled JavaScript module
  • test/generated/greeting.test.js - Jest test file (if enabled)

Watch Mode

Use watch mode for automatic recompilation during development:

# Watch a directory
gherkin watch features/

# Or use the start command (compile + watch)
gherkin start

The watcher will:

  • Monitor for file changes (add, modify, delete)
  • Automatically recompile affected files
  • Respect dependency order
  • Show compilation status in real-time
Tip: Press Ctrl+C to stop the watcher and see a summary of compiled files.
