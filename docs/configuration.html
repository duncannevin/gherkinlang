Configuration

Configure GherkinLang behavior with the .gherkinrc.json file.

Configuration File

GherkinLang looks for configuration in the following order:

  1. Path specified with --config option
  2. GHERKIN_CONFIG environment variable
  3. .gherkinrc.json in the current directory
  4. .gherkinrc.json in parent directories (up to root)

Creating a Config File

Run gherkin init to generate a config file, or create one manually:

{
  "output": {
    "directory": "dist",
    "moduleFormat": "commonjs",
    "target": "javascript"
  }
}

Output Options

Option Type Default Description
output.directory string "dist" Output directory for compiled files
output.moduleFormat string "commonjs" Module format: "commonjs" or "esm"
output.target string "javascript" Target language: "javascript" or "elixir"

Module Format Examples

CommonJS (default):

const add = (a, b) => a + b;
module.exports = { add };

ESM:

export const add = (a, b) => a + b;

AI Options

Option Type Default Description
ai.model string "claude-sonnet-4-20250514" Claude model to use for generation
ai.maxRetries number 3 Maximum retry attempts on failure
ai.temperature number 0 Generation temperature (0-1)
Note: Lower temperature values (closer to 0) produce more deterministic output.

Validation Options

Option Type Default Description
validation.syntax boolean true Enable JavaScript syntax validation
validation.purity boolean true Enable functional purity checks
validation.lint boolean true Enable ESLint validation

Purity Checks

When validation.purity is enabled, generated code is checked for:

  • No imperative loops (for, while)
  • No file system operations (fs.*)
  • No network calls (fetch, XMLHttpRequest)
  • No timers (setTimeout, setInterval)
  • No browser globals (window, document)
  • No Math.random()

Allowed:

  • console.log and console methods (for logging)
  • Date and Date.now()
  • State manager classes (with reduce + send methods)

Generation Options

Option Type Default Description
generation.jsdoc boolean true Generate JSDoc comments
generation.tests boolean true Generate Jest test files

Full Configuration Example

{
  "output": {
    "directory": "dist",
    "moduleFormat": "esm",
    "target": "javascript"
  },
  "ai": {
    "model": "claude-sonnet-4-20250514",
    "maxRetries": 3,
    "temperature": 0
  },
  "validation": {
    "syntax": true,
    "purity": true,
    "lint": true
  },
  "generation": {
    "jsdoc": true,
    "tests": true
  }
}

CLI Override

Command-line options override config file settings:

# Override output directory
gherkin compile features/ --output lib/

# Override module format
gherkin compile features/ --format esm

# Disable tests for single compile
gherkin compile features/ --no-tests
