CLI Reference

Complete reference for the GherkinLang command-line interface.

gherkin init

Initialize a new GherkinLang project with configuration and example files.

gherkin init [directory] [options]

Arguments

Argument Description
directory Target directory (defaults to current directory)

Options

Option Description
-t, --template <name> Project template: basic, library, api
-y, --yes Skip prompts, use defaults
-f, --force Overwrite existing files

Examples

# Interactive initialization
gherkin init

# Create project in new directory
gherkin init my-project

# Use API template with defaults
gherkin init my-api --template api --yes

# Force overwrite existing project
gherkin init . --force

gherkin compile

Compile feature files to JavaScript code.

gherkin compile <path> [options]

Arguments

Argument Description
path File or directory to compile (required)

Options

Option Description Default
-o, --output <dir> Output directory dist/
-f, --format <format> Module format: commonjs, esm commonjs
-t, --target <lang> Target language: javascript, elixir javascript
--no-cache Bypass compilation cache -
--no-tests Skip test generation -

Examples

# Compile a single file
gherkin compile features/calculator.feature

# Compile entire directory
gherkin compile features/

# Custom output with ESM format
gherkin compile features/ --output lib/ --format esm

# Skip cache for fresh compile
gherkin compile features/ --no-cache

# Compile without generating tests
gherkin compile features/ --no-tests

gherkin watch

Watch for file changes and automatically recompile.

gherkin watch <path> [options]

Arguments

Argument Description
path Directory to watch (required)

Options

Option Description Default
-o, --output <dir> Output directory dist/
--debounce <ms> Debounce delay in milliseconds 100
--initial Compile all files before watching -

Examples

# Watch features directory
gherkin watch features/

# Watch with initial compile
gherkin watch features/ --initial

# Custom debounce for slower systems
gherkin watch features/ --debounce 500
Tip: Press Ctrl+C to stop watching and see a summary of compiled files.

gherkin start

Convenience command that compiles and watches the features directory.

gherkin start [options]

Options

Option Description Default
-d, --dir <dir> Directory to watch features/
-o, --output <dir> Output directory dist/

Examples

# Start with defaults (features/ -> dist/)
gherkin start

# Watch custom directory
gherkin start --dir src/specs --output lib/

Global Options

These options are available for all commands:

Option Description
-c, --config <path> Path to config file
-v, --verbose Enable verbose output
--no-color Disable colored output
-h, --help Show help for command
-V, --version Show version number

Environment Variables

Variable Description
ANTHROPIC_API_KEY API key for Claude AI (required for compilation)
GHERKIN_CONFIG Path to config file (alternative to --config)
NO_COLOR Disable colored output when set
